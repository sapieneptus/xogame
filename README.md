# Game Maker

Make simple games for your children with Claude, without writing code. Claude builds and tests the game; you play it, record voices, and decide what goes in.

## Set up (once per computer, about 15 minutes)
1. Install **Git for Windows** from git-scm.com (accept all the default options). Claude needs it to save your work.
2. Install **Claude Code** (the Claude desktop app's Code tab, or Claude Code itself) and sign in.

## Start a new game
1. Make a copy of this kit for the new game. In Git Bash (installed in step 1), type:
   `git clone https://github.com/sapieneptus/xogame.git my-first-game`
   (One copy per game. Pick any name instead of `my-first-game`.)
2. Open that folder in Claude Code.
3. Say: **"Let's make a game."**

Within ten minutes you'll have a little toy on screen to try with the kids. Then Claude will help you decide what version 1 of your own game should be.

## Things you can say any time
- "What's next?" - where things stand and the next step.
- "Let me try it" - opens the game full screen.
- "That broke it" / "undo" - goes back to the last saved point. Nothing is ever lost.
- "Let's record voices" - opens the recording studio.
- "Update the kit" - brings in improvements to Game Maker without changing your game.

**To close a game:** hold **Ctrl + Shift + Q** for two seconds. (Little hands can't close it by accident, but the Windows key can still switch away, so stay nearby.)

Everything stays on your computer. Games have no internet, ads, accounts or data collection.
