# Wrap-up

1. `kit/tools/test.sh` must pass.
2. Update `STATE.md`: current_feature, next_action (one sentence), last_checkpoint, last_session_summary (three sentences at most), open questions.
3. Update `ROADMAP.md` (tick what's done) and refresh `roadmap.html`.
4. `kit/tools/checkpoint.sh "<plain summary>"`.
5. Tell them in two sentences what's done and what's next. If this conversation has become long, suggest starting a new conversation for the next feature ("I'll remember where we are; it keeps me sharp"). Otherwise offer to carry on.
